FH6 Tune Share Codes — Best Community Tunes

Updated May 22, 2026Updated as new tunes emerge

Share codes in FH6 let you instantly download a community tune built by another player and apply it to your car — no manual tuning required. These codes work for tuning setups, car designs, and even EventLab blueprints. This page covers the best community tunes for popular cars at launch, plus how to find and apply any share code.

How to use a share code

1
Make sure you own the car
Share codes are car-specific. You must already have the car in your garage before applying a tune to it.
2
Go to My Cars → Select the car → Tune Car
From the main menu: My Cars → select your car → scroll down to Tune Car. Or access it from any Festival site or Player House.
3
Select "Find Tunes" → enter share code
In the Tune menu, select Find Tunes and then enter the share code using the on-screen keyboard. Press Search to find the tune.
4
Download and apply
Preview the tune stats, then select Download and Apply. The tune immediately replaces your current setup. You can revert at any time.
Design codes vs tune codes
Share codes work for both car designs (liveries) and tuning setups — they use the same input system. When searching, the result will show whether it's a design or a tune. Make sure you're applying the right type.

Finding the latest codes
The best place to find up-to-date share codes is r/ForzaHorizon on Reddit — the community posts new tunes every Thursday after the Festival Playlist resets. Search "FH6 tune codes [week X]" for the current week's best picks. The in-game search by car name also surfaces top-rated community tunes by download count.

Estate farming tune code

For the Skill Point farming method (Subaru 22B + Estate), the best community-built Estate share code to start with is 127037763 — enter this in My Horizon → My Estates → Browse Community Estates. This is an Estate layout optimised for skill chain farming, not a car tune code.

Share codes for EventLab

EventLab blueprints also use the same share code system. The AFK Colossus farming race uses a custom EventLab track — search for it by entering "AFK farm Colossus" in the EventLab browse section, or look for the current top-rated code on Reddit's FH6 community this week.

Forza Horizon 6 launched with 618 confirmed cars across 7 performance classes. This tier list ranks the best cars in each class based on launch-week testing, community feedback, and cross-referencing multiple sources. Note: the meta is still forming — expect shifts as more players discover and share tune builds.

Important — meta still forming
FH6 launched May 19, 2026. The community is still testing tunes and builds. Rankings here reflect the best-known picks as of launch week. Check back weekly as more data comes in.

How the class system works

FH6 uses a Performance Index (PI) system to categorize cars. A car's PI depends on its stock stats plus any upgrades. Higher PI = better performance, but PI is capped per class. Here's the full class ladder:

  • D Class (100–500 PI) — Entry-level, slow, great for themed events
  • C Class (501–600 PI) — Daily drivers and light sports cars
  • B Class (601–700 PI) — Hot hatches, retro specials, tuner builds
  • A Class (701–800 PI) — Mid-game workhorse class, most campaign races
  • S1 Class (801–900 PI) — Modern supercars, late campaign
  • S2 Class (901–998 PI) — Hypercars, fastest road cars
  • R Class (NEW — 999 PI) — Race prototypes, Le Mans cars, track builds only

General tips for every class
A properly tuned A-Class car can beat an untuned S1 in the right event. Class placement matters more than raw prestige. For cross-country, choose the Dodge Viper GTS ACR Forza Edition or Subaru BRZ FE — acceleration and handling beat top speed since you need to hold speed through corners.
